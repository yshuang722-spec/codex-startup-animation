# macOS 验证范围

在一台 Apple Silicon Mac、macOS 27.2.1、Swift 6.4.2 上构建并进行离屏检查。窗口内动画经过人工试播，得到效果可接受的反馈；没有测量真实跟随延迟或帧率。

自动检查覆盖：

| 范围 | 数量或证据 |
| --- | --- |
| 启动阶段、超时、参数 | 20 项 |
| 窗口筛选、整窗覆盖与输入保护区域 | 15 项 |
| 指针移动及缩放计算 | 8 项 |
| 绘制语义 | 8 项 |
| WebKit Canvas 关键帧 | 12 张，覆盖 1440×900、900×650、390×844，以及减少动态效果模式 |
| 页面与原生跳过控件 | 离屏合成图及控件边界检查 |
| 构建与错误处理 | ARM64、临时签名完整性、无效输出目录返回失败 |

指针测试使用合成坐标，不向系统发送鼠标事件，也不拖动真实窗口；其中 120 个连续位置只验证计算没有累计偏差，不代表 120 FPS。

以下尚未验收：正式安装位置及 Dock 入口的首次图形启动、完全退出客户端后的完整冷启动、多显示器和跨屏拖动、窗口吸附及原客户端最小尺寸、macOS 13 等旧系统、Intel Mac、Developer ID 分发和 Apple 公证。

应用启动回调及 `isFinishedLaunching` 只说明应用层启动完成，不能证明 Codex 内部网页和会话完全加载。此版本没有接入客户端内部的就绪信号。

自动检查不会创建可见窗口或启动真实客户端。安装器可通过 `--destination` 指向独立的测试目录验证复制、重复安装、标识冲突和运行状态检查，不必写入“应用程序”。不要将后台检查结果当作上述真实交互场景已经通过。
